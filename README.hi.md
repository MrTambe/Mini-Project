# इवेंचर — कैंपस इवेंट मैनेजमेंट प्लेटफॉर्म

> एक ऐप। हर इवेंट। जीरो झंझट।

इवेंचर कॉलेजों, समुदायों और संस्थाओं के लिए एक फुल-स्टैक इवेंट मैनेजमेंट प्लेटफॉर्म है। यह छात्रों को इवेंट्स के लिए रजिस्टर करने, क्यूआर कोड से चेक-इन करने, सर्टिफिकेट कमाने, रियल-टाइम चैट करने और एडमिन डैशबोर्ड से सब कुछ मैनेज करने की सुविधा देता है — ईमेल ओटीपी ऑथेंटिकेशन, रियल-टाइम डेटा और एआई असिस्टेंस के साथ।

## ✨ विशेषताएं

### छात्र / उपयोगकर्ताओं के लिए
- **इवेंट ब्राउज़िंग** — आगामी, सक्रिय और पुराने इवेंट्स देखें विवरण सहित
- **इवेंट रजिस्ट्रेशन** — व्यक्तिगत या टीम इवेंट्स के लिए साइन अप करें
- **क्यूआर चेक-इन** — स्थान पर क्यूआर कोड स्कैन करें या चेक-इन कोड डालें
- **सर्टिफिकेट** — भाग लिए गए इवेंट्स के डिजिटल सर्टिफिकेट डाउनलोड करें
- **प्रोफाइल और सेटिंग्स** — अपना प्रोफाइल, शाखा, रोल नंबर और मोबाइल नंबर मैनेज करें
- **इवेंट चैट** — हर इवेंट के लिए रियल-टाइम ग्रुप चैट
- **निजी संदेश** — अन्य उपयोगकर्ताओं के साथ सीधे संदेश
- **सपोर्ट टिकट** — सपोर्ट टिकट बनाएं और ट्रैक करें

### एडमिन और टीम सदस्यों के लिए
- **एडमिन डैशबोर्ड** — इवेंट्स, रजिस्ट्रेशन और उपस्थिति का अवलोकन
- **इवेंट प्रबंधन** — इवेंट बनाएं, संपादित करें, रद्द करें और पूरा करें
- **टीम प्रबंधन** — स्वयंसेवक/टीम सदस्यों को जोड़ें और मैनेज करें
- **घोषणाएं** — सभी उपयोगकर्ताओं को संदेश प्रसारित करें
- **चेक-इन** — स्थान पर उपस्थिति सत्यापित करें
- **इवेंट विश्लेषण** — उपस्थिति दर, चेक-इन आंकड़े, विजेता ट्रैकिंग
- **टिकट** — उपयोगकर्ता सपोर्ट टिकट देखें और उत्तर दें
- **गूगल शीट्स सिंक** — इवेंट डेटा गूगल शीट्स में निर्यात करें
- **एआई चैट विजेट** — ऐप में एम्बेडेड एआई असिस्टेंट

### प्लेटफ़ॉर्म
- **ईमेल ओटीपी + पासवर्ड ऑथेंटिकेशन** (कॉन्वेक्स ऑथ)
- **भूमिका-आधारित एक्सेस कंट्रोल** (एडमिन / उपयोगकर्ता)
- **मोबाइल-रिस्पॉन्सिव** डिज़ाइन टेलविंड सीएसएस के साथ
- **डार्क मोड** सपोर्ट
- **एनिमेशन** फ्रेमर मोशन के माध्यम से
- **रियल-टाइम डेटा** कॉन्वेक्स के माध्यम से

## 🚀 क्विक स्टार्ट

### पूर्वापेक्षाएं
- नोड.जे.एस. 18+
- पीएनपीएम (सुझाया गया) या एनपीएम
- एक [कॉन्वेक्स](https://convex.dev) खाता (मुफ़्त टियर काम करता है)

### 1. रिपॉज़िटरी क्लोन करें

```bash
git clone https://github.com/MrTambe/Mini-Project.git
cd Mini-Project
```

### 2. निर्भरताएं इंस्टॉल करें

```bash
pnpm install
```

### 3. कॉन्वेक्स सेट अप करें

```bash
npx convex dev
```

यह एक कॉन्वेक्स तैनाती बनाता/लिंक करता है और `.env.local` में `VITE_CONVEX_URL` लिखता है।

### 4. पर्यावरण चर कॉन्फ़िगर करें

अपनी कॉन्वेक्स तैनाती पर ये सेट करें:

```bash
npx convex env set JWT_PRIVATE_KEY <आपका-ईएस256-निजी-कुंजी>
npx convex env set JWKS <आपका-जेडब्ल्यूकेएस-जेसओएन>
npx convex env set SITE_URL http://localhost:5173
npx convex env set SEED_ADMIN_SECRET <यादृच्छिक-गुप्त-स्ट्रिंग>
npx convex env set RESEND_API_KEY <आपका-रिसेंड-एपीआई-कुंजी>
```

वैकल्पिक (केवल विकास के लिए ओटीपी लॉगिंग):
```bash
npx convex env set DEV_CONSOLE_OTP true
```

पूर्ण टेम्पलेट के लिए `.env.example` देखें।

### 5. अपना पहला एडमिन सीड करें

```bash
pnpm seed:admin <ईमेल> <पासवर्ड> "<नाम>"
```

उदाहरण:
```bash
pnpm seed:admin admin@college.edu AdminPass123 "कॉलेज एडमिन"
```

### 6. सैंपल डेटा जोड़ें (वैकल्पिक लेकिन अनुशंसित)

```bash
pnpm seed:sample
# या पूर्ण डमी डेटासेट के लिए:
pnpm seed:dummy
```

### 7. विकास सर्वर शुरू करें

```bash
pnpm dev
```

अपने ब्राउज़र में http://localhost:5173 खोलें।

## 🔐 पर्यावरण चर

### क्लाइंट-साइड (`.env.local`, `npx convex dev` द्वारा लिखा गया)

| चर | विवरण |
|------|---------|
| `VITE_CONVEX_URL` | आपकी कॉन्वेक्स तैनाती URL |

### सर्वर-साइड (कॉन्वेक्स तैनाती पर `npx convex env set` द्वारा सेट करें)

| चर | विवरण | आवश्यक |
|------|---------|----------|
| `JWT_PRIVATE_KEY` | कॉन्वेक्स ऑथ ईएस256 हस्ताक्षर निजी कुंजी | हाँ |
| `JWKS` | सार्वजनिक कुंजी वाला जेसओएन वेब की सेट | हाँ |
| `SITE_URL` | फ्रंटएंड URL (जैसे `http://localhost:5173`) | हाँ |
| `SEED_ADMIN_SECRET` | एडमिन/डेमो डेटा सीडिंग के लिए गुप्त | हाँ |
| `RESEND_API_KEY` | ईमेल ओटीपी वितरण के लिए रिसेंड एपीआई कुंजी | हाँ (ईमेल वितरण के लिए) |
| `DEV_CONSOLE_OTP` | ईमेल के बजाय कंसोल पर ओटीपी लॉग करें (केवल विकास) | नहीं |
| `VLY_INTEGRATION_KEY` | वीएलवाई एआई/ईमेल/भुगतान इंटीग्रेशन कुंजी | ऑटो-सेट |
| `GOOGLE_SERVICE_ACCOUNT_EMAIL` | गूगल सेवा खाता ईमेल | शीट्स/डॉक्स के लिए |
| `GOOGLE_SERVICE_ACCOUNT_KEY` | गूगल सेवा खाता निजी कुंजी | शीट्स/डॉक्स के लिए |
| `GOOGLE_SHEETS_DB_ID` | गूगल शीट्स स्प्रेडशीट आईडी | शीट्स सिंक के लिए |
| `GOOGLE_DOCS_FOLDER_ID` | डॉक्स निर्यात के लिए गूगल ड्राइव फ़ोल्डर आईडी | डॉक्स इंटीग्रेशन के लिए |

## 🌐 भाषा सपोर्ट (हिन्दी / मराठी)

इवेंचर **अंग्रेज़ी**, **हिन्दी**, और **मराठी** का सपोर्ट करता है।

अनुवाद `src/lib/i18n/` में रहते हैं:
- `en.json` — अंग्रेज़ी
- `hi.json` — हिन्दी
- `mr.json` — मराठी

### भाषा कैसे बदलें

भाषा चयनकर्ता **सेटिंग्स** (और नेविगेशन ड्रॉपडाउन) में उपलब्ध है। भाषा चुनने पर आपकी पसंद सेव होती है और पूरा यूआई उस भाषा में री-रेंडर होता है।

### नई भाषा कैसे जोड़ें

1. `en.json` की प्रतिलिपि बनाकर `src/lib/i18n/<भाषा-कोड>.json` बनाएं
2. कुंजियां समान रखते हुए सभी मानों का अनुवाद करें
3. भाषा को `src/lib/i18n/index.ts` के चयनकर्ता में जोड़ें
4. नए अनुवाद ऑब्जेक्ट को एक्सपोर्ट करें

हुक उपयोग के लिए `src/hooks/use-translation.ts` देखें।

## 🤝 योगदान

हम योगदान का स्वागत करते हैं! शुरुआत कैसे करें:

1. रिपॉज़िटरी को **फोर्क** करें
2. **शाखा बनाएं**: `git checkout -b feature/आपकी-विशेषता-का-नाम`
3. **अपने बदलाव करें** और स्थानीय रूप से परीक्षण करें
4. **कमिट करें**: `git commit -m "feat: अपनी विशेषता जोड़ें"`
5. **पुश करें**: `git push origin feature/आपकी-विशेषता-का-नाम`
6. **पुल अनुरोध खोलें**

### योगदान के लिए सुझाए गए विचार / रोडमैप

यदि आप योगदान के लिए कुछ ढूंढ रहे हैं, तो यहाँ विचार हैं:

- [ ] **गूगल कैलेंडर सिंक** — इवेंट्स को उपस्थितकर्ताओं के कैलेंडर में पुश करें
- [ ] **रेज़रपे / स्ट्राइप भुगतान** — भुगतान इवेंट टिकट
- [ ] **व्हाट्सएप / एसएमएस सूचनाएं** — चेक-इन रिमाइंडर ट्विलियो या एमएसजी91 के माध्यम से
- [ ] **इवेंट फोटो गैलरी** — इवेंट फोटो अपलोड और साझा करें
- [ ] **सर्टिफिकेट पीडीएफ डाउनलोड** — सर्टिफिकेट को पीडीएफ के रूप में निर्यात करें (जेएसपीडीएफ पहले से इंस्टॉल है)
- [ ] **ईमेल डाइजेस्ट** — साप्ताहिक इवेंट सारांश रिसेंड के माध्यम से
- [ ] **यूनिट टेस्ट** — विटेस्ट + रिएक्ट टेस्टिंग लाइब्रेरी
- [ ] **सीआई/सीडी** — गिटहब एक्शन्स लिंट, बिल्ड और डिप्लॉय के लिए
- [ ] **एसईओ मेटा टैग** — लैंडिंग और इवेंट पेजों के लिए गतिशील मेटा टैग
- [ ] **अधिक भाषाएं** — गुजराती, तमिल, तेलुगु, बंगाली अनुवाद जोड़ें
- [ ] **पुश सूचनाएं** — इवेंट रिमाइंडर के लिए वेब पुश

### कोड शैली
- मौजूदा शैडसीएन यूआई सम्मेलनों का पालन करें (देखें `src/components/ui/`)
- शैडसीएन आदिम घटकों को अपरिवर्तित रखें; शैलियों को इनलाइन ओवरराइड करें
- सभी यूआई घटक मोबाइल-रिस्पॉन्सिव और डार्क-मोड संगत होने चाहिए
- एनिमेशन के लिए फ्रेमर मोशन का उपयोग करें
- टोस्ट के लिए `sonner` का उपयोग करें
- रूट्स को `<Protected>` या `<AdminProtected>` के साथ सुरक्षित करें

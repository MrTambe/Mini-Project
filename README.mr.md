# इवेंचर — कॅンपस इवेंट मॅनेजमेंट प्लॅटफॉर्म

> एक ॲप। सर्व इवेंट्स। शून्य ट्रबल।

इवेंचर हा महाविद्यालय, समुदाय आणि संस्था साठी एक फुल-स्टॅक इवेंट मॅनेजमेंट प्लॅटफॉर्म आहे. तो विद्यार्थ्यांना इवेंट्ससाठी नोंदणी करायला, क्यूआर कोडद्वारा चेक-इन करायला, सर्टिफिकेट मिळवायला, रिअल-टाइम चॅट करायला आणि एडमिन डॅशबोर्डद्वारा सर्वकाही मॅनेज करायला मदत करतो — ईमेल ओटीपी ऑथेंटिकेशन, रिअल-टाइम डेटा आणि एआय असिस्टन्ससोबत.

## ✨ वैशिष्ट्ये

### विद्यार्थी / वापरकर्तांसाठी
- **इवेंट ब्राउझिंग** — येत असलेले, सक्रिय आणि मागील इवेट्स तपासा तपशिलासह
- **इवेंट नोंदणी** — वैयक्तिक किंवा टीम इवेंट्ससाठी साइन अप करा
- **क्यूआर चेक-इन** — वेदन्याला क्यूआर कोड स्कॅन करा किंवा चेक-इन कोड टाका
- **सर्टिफिकेट** — उपस्थित राहिलेल्या इवेट्सचे डिजिटल सर्टिफिकेट डाउनलोड करा
- **प्रोफाइल आणि सेटिंग्ज** — तुमचा प्रोफाइल, शाखा, रोल नंबर आणि मोबाइल नंबर मॅनेज करा
- **इवेंट चॅट** — प्रत्येक इवेंटसाठी रिअल-टाइम ग्रुप चॅट
- **खास संदेश** — इतर वापरकर्त्यांशी थेट संदेश
- **सपोर्ट टिकट** — सपोर्ट टिकट बनवा आणि ट्रॅक करा

### एडमिन आणि टीम सदस्यांसाठी
- **एडमिन डॅशबोर्ड** — इवेंट, नोंदणी आणि उपस्थितीचा आढावा
- **इवेंट मॅनेजमेंट** — इवेंट तयार करा, संपादित करा, रद्द करा आणि पूर्ण करा
- **टीम मॅनेजमेंट** — स्वयंसेवक / टीम सदस्य जोडा आणि मॅनेज करा
- **घोषणा** — सर्व वापरकर्त्यांना संदेश प्रसारित करा
- **चेक-इन** — वेदन्याला उपस्थिती पडताळणी करा
- **इवेंट ॲनालिटिक्स** — उपस्थितीची tasa, चेक-इन आकडेवारी, विजेते ट्रॅकिंग
- **टिकट** — वापरकर्त्यांचे सपोर्ट टिकट पहा आणि उत्तर द्या
- **गूगल शीट्स सिंक** — इवेंट डेटा गूगल शीट्समध्ये एक्सपोर्ट करा
- **एआय चॅट विजेट** — ॲपमध्ये एम्बेडेड एआय असिस्टंट

### प्लॅटफॉर्म
- **ईमेल ओटीपी + पासवर्ड ऑथेंटिकेशन** (कॉन्वेक्स ऑथ)
- **भूमिका-आधारित एक्सेस कंट्रोल** (एडमिन / वापरकर्ता)
- **मोबाइल-रिस्पॉन्सिव्ह** डिझाइन टेलविंड सीएसएससह
- **डार्क मोड** समर्थन
- **एनिमेशन** फ्रेमर मोशनद्वारे
- **रिअल-टाइम डेटा** कॉन्वेक्सद्वारे

## 🚀 क्विक स्टार्ट

### पूर्वअपेक्षित गोष्टी
- नोड.जे.एस. १८+
- पीएनपीएम (शिफारस केला) किंवा एनपीएम
- एक [कॉन्वेक्स](https://convex.dev) खाते (मुफ्त टियर चालतो)

### 1. रिपॉझिटरी क्लोन करा

```bash
git clone https://github.com/MrTambe/Mini-Project.git
cd Mini-Project
```

### 2. डिपेंडेंसीज इंस्टॉल करा

```bash
pnpm install
```

### 3. कॉन्वेक्स सेट अप करा

```bash
npx convex dev
```

हे एक कॉन्वेक्स डिप्लॉयमेंट तयार करतो/लिंक करतो आणि `.env.local` मध्ये `VITE_CONVEX_URL` लिहतो.

### 4. पर्यावरण चल कॉन्फिगर करा

आपल्या कॉन्वेक्स डिप्लॉयमेंटवर हे सेट करा:

```bash
npx convex env set JWT_PRIVATE_KEY <आपली ईएस२५६ खाजgi की>
npx convex env set JWKS <आपली जेडब्ल्यूकेएस जेसॉन>
npx convex env set SITE_URL http://localhost:5173
npx convex env set SEED_ADMIN_SECRET <यादृच्छिक-गुप्त-स्ट्रिंग>
npx convex env set RESEND_API_KEY <आपली रिसेंड एपीआय की>
```

वैकल्पिक (फक्त विकासासाठी ओटीपी लॉगिंग):
```bash
npx convex env set DEV_CONSOLE_OTP true
```

पूर्ण टेम्पलेटसाठी `.env.example` पहा.

### 5. आपला पहला एडमिन सीड करा

```bash
pnpm seed:admin <ईमेल> <पासवर्ड> "<नाव>"
```

उदाहरण:
```bash
pnpm seed:admin admin@college.edu AdminPass123 "कॉलेज एडमिन"
```

### 6. सॅम्पल डेटा जोडा (वैकल्पिक पण शिफारस केलेले)

```bash
pnpm seed:sample
# किंवा पूर्ण डमी डेटासेटसाठी:
pnpm seed:dummy
```

### 7. विकास सर्व्हर सुरू करा

```bash
pnpm dev
```

आपल्या ब्राऊझरमध्ये http://localhost:5173 उघडा.

## 🔐 पर्यावरण चल

### क्लायंट-साइड (`.env.local`, `npx convex dev` द्वारे लिहिलेले)

| चल | वर्णन |
|------|---------|
| `VITE_CONVEX_URL` | तुमची कॉन्वेक्स डिप्लॉयमेंट URL |

### सर्व्हर-साइड (कॉन्वेक्स डिप्लॉयमेंटवर `npx convex env set` द्वारे सेट करा)

| चल | वर्णन | आवश्यक |
|------|---------|----------|
| `JWT_PRIVATE_KEY` | कॉन्वेक्स ऑथ ईएस२५६ स्वाक्षरी खाजgi की | होय |
| `JWKS` | सार्वजनिक कीसह जेसॉन वेब की सेट | होय |
| `SITE_URL` | फ्रंटएंड URL (उदा. `http://localhost:5173`) | होय |
| `SEED_ADMIN_SECRET` | एडमिन/डेमो डेटा सीडिंगसाठी गुप्त | होय |
| `RESEND_API_KEY` | ईमेल ओटीपी वितरणासाठी रिसेंड एपीआय की | होय (ईमेल वितरणासाठी) |
| `DEV_CONSOLE_OTP` | ईमेलऐवजी कंसोलवर ओटीपी लॉग करा (फक्त विकास) | नाही |
| `VLY_INTEGRATION_KEY` | व्हायएलवाय एआय/ईमेल/पेमेंट इंटिग्रेशन की | ऑटो-सेट |
| `GOOGLE_SERVICE_ACCOUNT_EMAIL` | गूगल सेवा खाता ईमेल | शीट्स/डॉक्ससाठी |
| `GOOGLE_SERVICE_ACCOUNT_KEY` | गूगल सेवा खाता खाजgi की | शीट्स/डॉक्ससाठी |
| `GOOGLE_SHEETS_DB_ID` | गूगल शीट्स स्प्रेडशीट आयडी | शीट्स सिंकसाठी |
| `GOOGLE_DOCS_FOLDER_ID` | डॉक्स एक्सपोर्टसाठी गूगल ड्राइव फोल्डर आयडी | डॉक्स इंटिग्रेशनसाठी |

## 🌐 भाषा समर्थन (हिंदी / मराठी)

इवेंचर **इंग्रजी**, **हिंदी**, आणि **मराठी** चे समर्थन करतो.

अनुवाद `src/lib/i18n/` मध्ये आहेत:
- `en.json` — इंग्रजी
- `hi.json` — हिंदी
- `mr.json` — मराठी

### भाषा कशी बदलायची?

भाषा निवडक **सेटिंग्ज** (आणि नेविगेशन ड्रॉपडाउनमध्ये) उपलब्ध आहे. भाषा निवडल्यावर तुमची पसंती साठवते आणि संपूर्ण यूआय ती भाषा मध्ये री-रेंडर होते.

### नवीन भाषा कशी जोडायची?

१. `en.json` ची प्रतिकृती करून `src/lib/i18n/<भाषा-कोड>.json` तयार करा
२. की समान ठेवून सर्व मूल्यांचे अनुवाद करा
३. भाषा `src/lib/i18n/index.ts` च्या निवडकात जोडा
४. नवीन अनुवाद ऑब्जेक्ट एक्सपोर्ट करा

हुक वापरासाठी `src/hooks/use-translation.ts` पहा.

## 🔌 इंटिग्रेशन

### गूगल शीट्स (पहिल्यांपासच लागू केला आहे)
इवेंट्स, सहभागी आणि कर्मचारी डेटा गूगल शीट्स स्प्रेडशीटमध्ये एक्सपोर्ट करा. सेटअपसाठी [`integrations.md`](./integrations.md) पहा.

### गूगल डॉक्स (नवीन)
इवेंट रिपोर्ट, सर्टिफिकेट आणि घोषणा गूगल डॉक्स दस्तऐवज म्हणून एक्सपोर्ट करा. पूर्ण सेटअप गाइडसाठी [`integrations.md`](./integrations.md) पहा.

### व्हायएलवाय इंटिग्रेशन (एआय, ईमेल, पेमेंट्स)
`@vly-ai/integrations` द्वारे एआय पूर्णता, एम्बेडिंग, ईमेल पाठवणे आणि पेमेंट इंटेंट. [`integrations.md`](./integrations.md) पहा.

### इतर इंस्टॉल केलेली लायब्ररीज
- `googleapis` — गूगल एपीआय क्लायंट
- `@google/generative-ai` — गूगल जेमिनी एआय
- `axios` — एचटीटीपी क्लायंट
- `jspdf` + `jspdf-autotable` — पीडीएफ जनरेशन
- `leaflet` + `react-leaflet` — मॅप्स

## 🤝 योगदान

आपले योगदान आपले स्वागत आहे! सुरुवात कशी करायची:

१. रेपो **फोर्क** करा
२. **ब्रांच तयार करा**: `git checkout -b feature/तुमची-वैशिष्ट्य-नाव`
३. **बदल करा** आणि स्थानिकरित्या चाचणी करा
४. **कमिट करा**: `git commit -m "feat: तुमची वैशिष्ट्य जोडा"`
५. **पुश करा**: `git push origin feature/तुमची-वैशिष्ट्य-नाव`
६. **पुल रिक्वेस्ट उघडा**

### योगदानासाठी सुझावित कल्पना / रोडमॅप

जर तुम्हाला योगदानासाठी काही शोधत असाल, तर येथे कल्पना आहेत:

- [ ] **गूगल कॅलेंडर सिंक** — उपस्थितकर्त्यांच्या कॅलेंडरवर इवेंट्स पुश करा
- [ ] **रेजरपे / स्ट्राइप पेमेंट्स** — पेड इवेंट तिकिटे
- [ ] **व्हॉट्सअप / एसएमएस सूचना** — ट्विलिओ किंवा एमएसजी९१ द्वारे चेक-इन रिमाइंडर
- [ ] **इवेंट फोटो गॅलरी** — इवेंट फोटो अपलोड आणि शेअर करा
- [ ] **सर्टिफिकेट पीडीएफ डाउनलोड** — सर्टिफिकेट पीडीएफ म्हणून एक्सपोर्ट करा (जेएसपीडीएफ आधीच इंस्टॉल आहे)
- [ ] **ईमेल डायजेस्ट** — साप्ताहिक इवेंट सारांश रिसेंड द्वारे
- [ ] **यूनिट टेस्ट्स** — विटेस्ट + रिआक्ट टेस्टिंग लायब्ररी
- [ ] **सीआय/सीडी** — गिटहब एक्शन्स लिंट, बिल्ड आणि डिप्लॉयसाठी
- [ ] **एसईओ मेटा टॅग्स** — लँडिंग आणि इवेंट पेजसाठी डायनॅमिक मेटा टॅग्स
- [ ] **अधिक भाषा** — गुजराती, तमिळ, तेलुगू, बंगाली अनुवाद जोडा
- [ ] **पुश नोटिफिकेशन्स** — इवेंट रिमाइंडरसाठी वेब पुश

### कोड शैली
- सध्याच्या शॅडसीएन यूआय कन्व्हेन्शन्स फॉलो करा (पाहा `src/components/ui/`)
